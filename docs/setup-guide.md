# Setup guide

Public guide for running SafeEyes. This fills in as the pipeline and deployment take shape.

## Development (laptop)

Prerequisites and environment setup will be documented here: Python version, dependency installation, and how to run the training and evaluation harness.

## Edge runtime (Raspberry Pi 4B)

Deployment steps will be documented here: preparing the Pi, installing the runtime, loading the quantized models, connecting the camera, and launching the real time loop.

## Datasets

The pipeline trains and evaluates on public datasets. How to obtain them is documented in `docs/source/datasets.md`.
