# Model card: eye state classifier

A compact convolutional network that labels a single eye crop as open or closed.
It is one input to the perception stage, cross checked against the eye aspect
ratio computed from the same landmarks. For the system overview see
[docs/architecture.md](../architecture.md); for the dataset and split details see
[docs/source/datasets.md](../source/datasets.md).

## Intended use

Part of an assistive driver monitoring prototype. It estimates eye openness from
an eye crop to feed the downstream fatigue signals (blink dynamics and the
proportion of eye closure over time). It is not a medical or safety of life
device and makes no diagnostic claim.

## Architecture

A small two block convolutional stack (16 then 32 channels, each followed by
ReLU and max pooling), an adaptive average pool to a fixed 4 by 4 grid, then a
fully connected head with dropout producing two class logits. The adaptive pool
makes the model independent of the exact crop resolution, so the same definition
works whatever eye crop size the perception stage uses. The network is kept
small on purpose so it can run in real time on the edge device after
quantization.

Input: a single channel eye crop, scaled to a fixed square size and normalized
to the range zero to one. Output: two logits, open versus closed.

## Training data and protocol

Trained on the MRL Eye Dataset, where each image is labeled open or closed in its
filename. The data is partitioned with a subject independent split: no subject
appears in both training and evaluation, so the held out accuracy reflects
performance on people the model never saw during training. The split is fixed and
recorded as manifests, and the eye state label mapping is open to one and closed
to zero.

## Reported metric

Held out accuracy on the subject independent MRL test split is regenerated by the
training command, which writes the number to a metrics file alongside the
checkpoint:

```
python -m safeeyes.models.train_eye_state \
    --train-manifest splits/mrl-eye/train.csv \
    --val-manifest splits/mrl-eye/test.csv \
    --image-root data/mrl-eye --out models/eye_state.pt \
    --metrics-out docs/ml/eye-state-metrics.json
```

The accuracy figure is filled in here from that metrics file after a training run
on the fixed split, so the number always traces back to a specific run and a
specific partition rather than to a remembered value. Until that run is recorded,
this card states the protocol, not a number.

## Limitations

- Trained on infrared eye imagery captured in a research setting, not on a wide
  range of real driving conditions; generalization to very different cameras and
  lighting is not characterized here.
- The classifier answers open or closed only. It does not identify a person and
  builds no face profile (see the privacy threat model under docs/security).
- Per subject open and closed counts vary, so any residual class imbalance in a
  split is recorded in that split's summary and handled at training time with
  class weighting rather than by mixing subjects across splits.
